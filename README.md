# F1-INTELLIGENCE-DASHBOARD
PROJECT REPORT
FORMULA 1 RACE INTELLIGENCE ANALYSIS USING TABLEAU
1. Introduction

Formula 1 (F1) is one of the most prestigious and technologically advanced motorsport competitions in the world. It involves highly skilled drivers, advanced racing technologies, strategic decision-making, and intense competition among constructors. Every Formula 1 season generates a large amount of data related to race results, driver performance, team standings, tyre strategies, circuit participation, and technical failures.

The Formula 1 Race Intelligence Analysis project focuses on analyzing historical Formula 1 racing data using Tableau, a powerful data visualization and business intelligence tool. The project aims to transform raw racing data into meaningful visual insights through interactive charts, dashboards, and stories.

The analysis covers 6,464 race records across 17 seasons and explores several important aspects of Formula 1, including driver performance, constructors' championship trends, tyre compound strategies, circuit participation, driver reliability, Did Not Finish (DNF) patterns, and global podium achievements.

By presenting complex racing statistics in an interactive and visually understandable format, this project helps stakeholders such as team strategists, race engineers, motorsport journalists, technical analysts, and Formula 1 enthusiasts make informed decisions.

2. Problem Statement

Formula 1 generates extensive historical data, making it difficult to identify meaningful patterns and trends through traditional data analysis methods.

Understanding driver performance, comparing team championship results, evaluating tyre strategies, and identifying technical failures require effective data analysis and visualization techniques.

Without a centralized and interactive analytical platform, stakeholders may find it challenging to compare historical performance, identify areas of improvement, and communicate important findings.

Therefore, this project aims to develop an interactive Tableau-based Formula 1 Race Intelligence Dashboard that converts historical racing data into meaningful visualizations and actionable insights.

3. Objectives of the Project

The primary objectives of this project are:

To analyze historical Formula 1 race records across 17 seasons.
To evaluate driver performance using cumulative championship points.
To compare constructors' championship performance across different seasons.
To analyze the impact and usage of Soft, Medium, Hard, and Intermediate tyre compounds.
To identify countries that have hosted the highest number of Grand Prix races.
To analyze driver reliability and Did Not Finish (DNF) patterns.
To identify common technical failures such as engine failures, brake failures, collisions, and mechanical issues.
To visualize podium achievements by drivers, constructors, and nationalities.
To develop interactive dashboards that allow users to explore racing data.
To provide data-driven recommendations for improving team performance and race strategies.
4. Scope of the Project

The scope of this project is to analyze Formula 1 historical racing data and present the findings through interactive Tableau visualizations.

The project covers the following major analytical areas:

Driver Performance Analysis: Evaluating individual driver achievements and cumulative championship points.
Constructors' Championship Analysis: Comparing team performance and identifying championship trends.
Tyre Strategy Analysis: Examining the usage of different tyre compounds and their relationship with race outcomes.
Circuit Analysis: Studying race participation across different circuits and countries.
Driver Reliability Analysis: Evaluating DNF patterns and technical failures.
Podium Achievement Analysis: Understanding driver-wise and team-wise podium distributions.

The project primarily focuses on historical data analysis rather than real-time race prediction or live telemetry monitoring.

5.2 Dataset

The project uses a Formula 1 historical dataset containing 6,464 race records across 17 seasons. The dataset supports analysis of drivers, constructors, race results, tyre compounds, circuits, podiums, and race completion status.

6. Project Methodology

The project follows a systematic data analytics process.

Step 1: Data Collection

Historical Formula 1 racing data is collected from the available dataset. The data contains information about race records, drivers, constructors, circuits, tyre compounds, results, and failure statuses.

Step 2: Data Cleaning

The collected data is examined to improve its quality and consistency.

The cleaning process includes:

Identifying and handling missing values.
Removing duplicate records where appropriate.
Correcting inconsistent data formats.
Standardizing driver, team, and circuit names.
Checking data types and relationships between fields.
Step 3: Data Preparation

The cleaned dataset is organized into suitable structures for analysis. Relevant fields and calculated measures are prepared for driver points, team performance, tyre usage, podium counts, and DNF analysis.

Step 4: Data Visualization

Different Tableau charts are created to represent important Formula 1 performance indicators.

These include:

Bar charts.
Line charts.
Stacked bar charts.
Pie charts.
Geographic maps.
Highlight tables.
Comparative dashboards.
Step 5: Dashboard Development

The individual visualizations are combined into interactive dashboards. Filters and other interactive features allow users to explore the data according to drivers, teams, seasons, circuits, and tyre compounds.

Step 6: Tableau Story Development

A Tableau Story is created to present the analysis in a logical sequence. Each story point focuses on a particular aspect of Formula 1 race intelligence, helping users understand the findings step by step.
